# v0.1.0 Beta — Build 20261118.6

This beta adds the CloakRoll name and a Retina icon to the library sidebar. Settings stays visible below the scrolling library and backup lists. The Settings window can be resized, and About provides signed updates.

**Requires Apple silicon and macOS 26 or later.** Built with Xcode 27.2 on macOS 27.2.1.

## Install and update

1. Download **CloakRoll-v0.1.0-beta.20261118.6.dmg** from this release. The SHA-256 hashes of the DMG and Sparkle ZIP are in **SHA256SUMS.txt**.
2. Open the DMG, drag **CloakRoll** to **Applications**, eject the disk and launch the installed app. This prerelease is ad-hoc signed and unnotarized. Review [Apple’s opening guidance](https://support.apple.com/en-us/102445) if first launch is blocked.
3. Open **Settings → About → Check for Updates**. Automatic checks and downloads are off by default. Sparkle verifies the signed website feed and the update ZIP served by GitHub.

## Verification

All 418 core and 246 hosted tests passed. Native checks cover the sample library, photo information, disconnected state, Settings and the update dialog.
