# CloakRoll 0.1.0 beta — build 20261028.3

Local beta prepared and installed 28 October 2026. **Apple silicon only, macOS 26 or later.**
Runtime validation was on Apple silicon with macOS 27.2. Locally ad-hoc signed, not notarized
or published. This supersedes the universal/macOS 14 target of earlier local betas.

## Changes

- The app, local package, installer and landing page now target modern Apple silicon Macs.
  Packaging checks the real executable architecture and minimum OS alongside bundle metadata.
- Backup byte progress appears as a circular Dock ring, matching CloakDrop. It remains observed
  when the library window closes, coalesces whole-percent redraws and clears when the run ends.
  A full ring still waits for verification and history finalization before backup completion.
- Settings retains the native family layout and reopens on General. Five taps on the About icon
  reveal Matrix rain; tap again to stop. Leaving About resets it. Reduce Motion uses a still frame.
- Previous missing-original continuation, persistent failure explanations, incremental verification,
  shared photo/video folders and recovery features remain included. See [previous notes](v0.1.0-beta.20261028.2.md).

## Install

Open `CloakRoll-v0.1.0-beta.20261028.3.dmg`, drag CloakRoll to Applications, launch it and eject the installer.
For a trusted unnotarized build blocked by macOS, follow [Apple's opening guidance](https://support.apple.com/en-us/102445).
Connect/unlock the iPhone over USB and select a backup destination. Keep another copy of
irreplaceable originals while evaluating the beta; USB exposure is not complete iCloud coverage.
