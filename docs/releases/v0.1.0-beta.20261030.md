# v0.1.0 Beta — Build 20261030

This beta adds a **Buy me a coffee** link in About, matching CloakDrop, and refreshes compatible project dependencies. Built as an optimized Apple silicon **Release** with **Xcode 27.1 (27A9275)** and the **macOS 27.0 SDK**.

**Requires:** Apple silicon and macOS 26 or later. The app reports **0.1.0 (20261030) · Beta**.

## What changed

- Added **About → Buy me a coffee**, with the native cup icon and link row, opening [Sumit's Ko-fi page](https://ko-fi.com/sumitsahoo21) only when selected.
- Updated the companion website to **Astro 7.4.4** and **Wrangler 4.156.0**, refreshed compatible transitive dependencies and removed a redundant Undici override. Its clean dependency audit reports **zero vulnerabilities**. Website production deployment remains separate.
- Checked the native and installer libraries against their official releases. **GRDB 7.11.1**, **dmgbuild 1.6.7**, **ds_store 1.3.3** and **mac_alias 2.2.3** are already current; the latter three are build-time tools and do not ship in the app.
- Kept **TypeScript 6.0.3**, the newest supported version: Astro Check 0.9.12's peer range excludes TypeScript 7. Wrangler's upstream Miniflare/workerd dependency pins are retained. See the [dependency audit](https://github.com/cloakyard/cloakroll/blob/843ba9d9c3b5030a3981a10fcf6816a4e6109326/docs/verification/SUPPORT-BETA-2026-10-30.md).

Original backup, incremental verification and recovery behavior are unchanged. No accounts, analytics, media uploads or app-operated network services were added.

## Install

Installer: **CloakRoll-v0.1.0-beta.20261030.dmg** (6,620,001 bytes).

1. Download the DMG from this official release, open it and drag CloakRoll to Applications.
2. Open CloakRoll from Applications. If macOS blocks this locally signed beta, use **System Settings → Privacy & Security → Open Anyway** for the trusted copy from this repository. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Eject the installer. Connect and unlock your iPhone over USB, accept Trust if prompted, and choose your backup folder.

Verify the installer with:

```bash
shasum -a 256 ~/Downloads/CloakRoll-v0.1.0-beta.20261030.dmg
```

Expected SHA-256:

```text
8b842d05dabe24f3a1e9119022d78eabb03b811737742653aea5a5c93b0d537c
```

`SHA256SUMS.txt` is also attached. The installer includes an Install Guide.

## Beta limitations

**Ad-hoc signed; not Developer ID signed or notarized.** Sandbox and hardened runtime remain enabled. Clean-Mac Gatekeeper and minimum macOS 26 runtime acceptance remain open; this build was checked on macOS 27.2.

No new physical iPhone backup was run for this update. Final large-backup, cable/external-drive interruption, full-volume, new-capture/reconnect, sleep/wake and two-phone acceptance remain open, alongside sustained real-library performance and full VoiceOver/accessibility checks. Software tests do not close those gates.

USB exposure is not complete iCloud Photos coverage. Live Photo originals are preserved, but in-app animated playback and restore-to-iPhone are not implemented; edited/effect variants need further hardware validation. Keep another independent copy of irreplaceable originals while evaluating the beta.
