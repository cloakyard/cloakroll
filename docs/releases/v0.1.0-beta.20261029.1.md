# CloakRoll 0.1.0 beta — build 20261029.1

Prepared and installed 29 October 2026. **Apple silicon only, macOS 26 or later.**
Locally ad-hoc signed; not notarized or published. Runtime validation used macOS 27.2.

## Changes

Media Info identifies a Live Photo's Photo and Motion originals, labels the still preview and
explains keeping both files. Eight regression cases cover HEIC/JPEG pairs with adjustment files,
repeated filenames and missing-motion retry in dated/flat per-iPhone folders. Original bytes
are preserved; an incomplete pair is never counted as complete. Animated Live Photo playback
inside CloakRoll is not implemented. See [Live Photo support](../LIVE-PHOTOS.md).

The repository now uses `dev` for ongoing development and PRs into `main`. A read-only Website
check validates the site and dry-runs its Worker. [Cloudflare setup](../../apps/site/README.md#cloudflare-workers-builds)
is documented for the user's later deployment; this release does not deploy the site.

unnotarized beta blocked by macOS, follow [Apple's opening guidance](https://support.apple.com/en-us/102445).

edited/effect Live Photo variants and independent playback, sustained real-library profiling,
