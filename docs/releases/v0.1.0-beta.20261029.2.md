# v0.1.0 Beta — Build 20261029.2

CloakRoll's first public beta brings original iPhone photo and video backups to the Mac over USB, with incremental copying, local verification and folders you control. This is an optimized Apple silicon **Release** build using **Xcode 27.1 (27A9275)** and the **macOS 27.0 SDK**.

**Requires:** Apple silicon and macOS 26 or later. The app reports **0.1.0 (20261029.2) · Beta**. Build numbers follow CloakDrop's `YYYYMMDD` convention, with `.N` for additional builds on the same day.

## What changed

- Browse USB-exposed photos, videos, RAW and Live Photos with filename search, capture-date filters, date groups, previews and camera metadata.
- Back up original components without conversion or deletion on the iPhone. Live Photo stills, motion originals and exposed adjustment companions are kept together; Info explains their roles.
- Copy only missing originals after checking saved-file identity, size and SHA-256. Each iPhone remembers its destination, with separate device folders and Year/Month or One Folder organization.
- Follow measured progress in the app and Dock, stop or retry work, and review paged offline history. Missing USB originals leave a truthful incomplete result while unrelated available originals can continue.
- Check saved originals and rebuild lost history from portable recovery records. Media-only folders can use an explicit one-time source verification over USB.
- Native macOS controls, keyboard selection, light/dark appearance, family Settings and an Air drag-to-Applications installer.

No accounts, analytics, media uploads or app-operated network services. GRDB 7.11.1 is the only third-party Swift dependency; its license and privacy manifest are included in the app.

## Install

Installer: **CloakRoll-v0.1.0-beta.20261029.2.dmg** (6,620,320 bytes).

1. Download the DMG from this official release, open it and drag CloakRoll to Applications.
2. Open CloakRoll from Applications. If macOS blocks this locally signed beta, use **System Settings → Privacy & Security → Open Anyway** for the trusted copy from this repository. See [Apple's guidance](https://support.apple.com/en-us/102445).
3. Eject the installer. Connect and unlock your iPhone over USB, accept Trust if prompted, and choose a backup folder.

Verify the installer with:

```bash
shasum -a 256 ~/Downloads/CloakRoll-v0.1.0-beta.20261029.2.dmg
```

Expected SHA-256:

```text
b2e3a7408bc66c954254161dba2116576c0b645aa303e1c8c3219026ecc89851
```

`SHA256SUMS.txt` is also attached. The installer includes an Install Guide.

## Beta limitations

- **Ad-hoc signed; not Developer ID signed or notarized.** Sandbox and hardened runtime remain enabled. Clean-Mac Gatekeeper acceptance and minimum macOS 26 runtime acceptance remain open; this release was checked on macOS 27.2.
- Only originals exposed by the iPhone over USB are available. iCloud-only originals may be absent, and Photos albums are not reconstructed from DCIM folders. Keep another independent copy of irreplaceable originals while evaluating the beta.
- Final large-backup, new-capture/reconnect, cable/external-drive interruption, full-volume, sleep/wake and two-physical-iPhone acceptance remain open. Automated tests and prior bounded imports do not close those gates.
- Sustained physical-library profiling, full VoiceOver spoken feedback and the remaining accessibility variants are still pending.
- Live Photo originals are preserved, but animated playback inside CloakRoll is not implemented. Edited/effect variants and playback in independent viewers need further hardware validation. Restore to an iPhone is not implemented.
