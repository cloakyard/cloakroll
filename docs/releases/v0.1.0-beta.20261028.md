# CloakRoll 0.1.0 beta — build 20261028

Local beta candidate, prepared 28 October 2026. Not yet published on GitHub.
Targets macOS 14+; universal Apple silicon/Intel binary. Actual runtime checks are on
Apple silicon with macOS 27.2. **Locally ad-hoc signed; not notarized.**

## Included

- USB browsing and original photo/video/RAW/Live Photo backup.
- Verified incremental reuse, separate iPhone folders and remembered destinations.
- Year/Month or One Folder organization, compact progress and Stop/retry.
- Offline history, saved-file checks and folder-based history rebuilding.
- Capture-date/filename filtering, camera metadata, selection and keyboard navigation.
- Family-aligned Settings, Privacy, About, bug-report links and bundled license notices.
- Air drag-to-Applications DMG and reproducible dated packaging.

## Install

Open the DMG, drag CloakRoll to Applications and launch it, then eject the installer.
Connect and unlock your iPhone, accept Trust if asked and choose a backup folder.
For a trusted unnotarized copy blocked by macOS, follow
[Apple’s opening guidance](https://support.apple.com/en-us/102445).

Keep another independent copy of irreplaceable originals while evaluating this beta.
Only media exposed over USB is available; iCloud-only media may be absent. Restore to iPhone
is not implemented. No iPhone app is needed for backup.

Expected artifact: `CloakRoll-v0.1.0-beta.20261028.dmg` in
`apps/macos/build/Beta-0.1.0-20261028/`, with `SHA256SUMS.txt`, `build-manifest.json`
and `app-inventory.json`. Final checksum and checks are recorded after validation in
[the dated audit](../verification/BETA-2026-10-28.md).

## Known limits

Final cable/removable-drive interruption, full-disk/remount, new-capture reconnect,
sustained memory/scroll profiling, full assistive-technology and older-OS/Intel runtime
checks remain open. No Developer ID/notarization or clean-Mac Gatekeeper acceptance is claimed.
Recorded bounded real-device evidence and remaining gates are in [Release](../RELEASE.md).

## Feedback

Use **Settings → About → Report a Bug**. Include the version/build, macOS/iOS versions,
destination type and reproduction steps. Exclude personal photos, identifiers, private paths
and backup databases. Check **Backup History → Check Saved Files** when investigating a backup.
