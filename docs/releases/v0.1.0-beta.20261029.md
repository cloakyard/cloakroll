# CloakRoll 0.1.0 beta — build 20261029

Local beta prepared and installed 29 October 2026. **Apple silicon only, macOS 26 or later.**
Runtime checks used macOS 27.2. Locally ad-hoc signed, not notarized or published.

## Changes

This is a software-closeout build with the same app features as [20261028.3](v0.1.0-beta.20261028.3.md).
It validates the corrected macOS 26 performance probe and strengthened beta process: capture
one clean source revision and reject changed source between stages. The process now runs its
own regression tests and a 10k metadata smoke test alongside the app checks.

Native keyboard selection, search and Info focus were checked. Actual system Reduce Motion and
Reduce Transparency checks passed and preferences were restored. Current 10k/50k/100k metadata
measurements and a bounded 100k-sample Instruments trace are recorded in
[the closeout audit](../verification/CLOSEOUT-2026-10-29.md). They do not establish sustained
real-media or USB performance.

## Install

Open `CloakRoll-v0.1.0-beta.20261029.dmg`, drag CloakRoll to Applications, launch it and eject
the installer. For a trusted unnotarized build blocked by macOS, follow
[Apple's opening guidance](https://support.apple.com/en-us/102445).
Connect/unlock the iPhone over USB and choose a backup destination. Keep another independent
copy of irreplaceable originals while evaluating the beta; USB exposure is not complete iCloud
coverage.
