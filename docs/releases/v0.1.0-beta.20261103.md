# v0.1.0 Beta — Build 20261103

This beta adds backup health, explicit continuation of unfinished backups, offline browsing of saved originals, storage review and optional local notifications. It also fixes retry, preview-lifetime, notification-ordering and keyboard-accessibility defects found during the follow-up audits. Built as an optimized Apple silicon **Release** with **Xcode 27.2 (27B52)** and the **macOS 27.2 SDK**.

**Requires:** Apple silicon and macOS 26 or later. The app reports **0.1.0 (20261103) · Beta**.

## What changed

- **Backup Health** shows recorded outcomes, dated saved-file checks, folder access and unknown USB coverage separately. Check Saved Files performs a read-only integrity check.
- **Continue an unfinished backup** preserves its selection and folder organization across relaunch. Continuation rechecks completed originals and restarts unfinished components after matching the original phone, folder and resource identities. Same-connection retries also work for session-only identities; these cannot be reused after reconnect.
- **Saved Originals** browses recorded local files without a connected iPhone, with bounded pages, date/type filters, native Quick Look and Reveal in Finder. Folder access remains active while reads settle; cancelled or superseded requests cannot replace the current preview.
- **Storage review** shows original-component counts, verified reuse, additional bytes, destination and free capacity before Start. It blocks known shortfalls and revalidates the selection and folder before transferring.
- **Optional local notifications** report completion or attention and offer a configurable overdue-backup reminder. They are off by default, contain no media names or paths, and require explicit permission. Settings includes a test notice and an explicit check for macOS-reported delivery.
- Improved **keyboard and accessibility navigation** for Health, saved-item disclosures, Preview/Reveal, filters and review sheets. Backup facts expose separate labels and values; Return/Escape shortcuts and focus return work through continuation and review.
- Removed obsolete presentation branches, unused helpers/imports and dangling preview work. The existing **Buy me a coffee** link still opens [Sumit's Ko-fi page](https://ko-fi.com/sumitsahoo21).

Originals remain unchanged on the iPhone. No accounts, analytics, media uploads or app-operated network services were added. Dependency versions retain the compatible updates from the previous beta.

## Install

Installer: **CloakRoll-v0.1.0-beta.20261103.dmg** (6,905,017 bytes).

1. Download the DMG from this official release, open it and drag CloakRoll to Applications.
2. Open CloakRoll from Applications. If macOS blocks this locally signed beta, follow [Apple's guidance](https://support.apple.com/en-us/102445) for opening a trusted app from this repository.
3. Eject the installer. Connect and unlock your iPhone over USB, accept Trust if prompted, and choose your backup folder.

Verify the installer with:

```bash
shasum -a 256 ~/Downloads/CloakRoll-v0.1.0-beta.20261103.dmg
```

Expected SHA-256:

```text
a4e50990e4e03bc0c07a4c454b8fa195c4b3d858311f606569c39a0107e8165a
```

`SHA256SUMS.txt` is also attached. The installer includes an Install Guide.

## Beta limitations

**Ad-hoc signed; not Developer ID signed or notarized.** Sandbox and hardened runtime remain enabled. The existing local signing process is retained at the user's request; paid-account signing can be added later. Clean-Mac Gatekeeper and minimum macOS 26 runtime acceptance remain open because no additional test environment is available. This build was checked on macOS 27.2.

No new physical iPhone backup was run for this update. Final large-backup, cable/external-drive interruption, full-volume, new-capture/reconnect, sleep/wake and two-phone acceptance remain open, alongside sustained real-library performance. Full VoiceOver spoken/caption-feedback acceptance remains open because its feedback surface could not be observed through the control tool. Software and generated-data checks do not close these gates.

USB exposure is not complete iCloud Photos coverage. Live Photo originals are preserved, but in-app animated playback and restore-to-iPhone are not implemented; edited/effect variants need further hardware validation. Keep another independent copy of irreplaceable originals while evaluating the beta.
