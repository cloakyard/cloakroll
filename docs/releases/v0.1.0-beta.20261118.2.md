# v0.1.0 Beta — Build 20261118.2

This beta adds signed updates in About and the shared Air installer. It retains USB original-media backup, Backup Health, saved-original browsing and explicit continuation of unfinished backups. Users of the November 3 beta or earlier should install this DMG once to enable in-app updates.

**Requires Apple silicon and macOS 26 or later.** Built with Xcode 27.2 (27B52) on macOS 27.2.1.

## Install and update

1. Download **CloakRoll-v0.1.0-beta.20261118.2.dmg** from this release. The SHA-256 hashes of the DMG and Sparkle ZIP are in **SHA256SUMS.txt**.
2. Open the DMG, drag **CloakRoll** to **Applications**, eject the disk and launch the installed app. This prerelease is ad-hoc signed and unnotarized. Review [Apple’s opening guidance](https://support.apple.com/en-us/102445) if first launch is blocked.
3. Open **Settings → About → Check for Updates**. Automatic checks and downloads are off by default. Sparkle verifies the signed website feed and the update ZIP served by GitHub.
