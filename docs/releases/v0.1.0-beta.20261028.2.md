# CloakRoll 0.1.0 beta — build 20261028.2

Local beta candidate, prepared and installed 28 October 2026. Not published on GitHub.
Universal Apple silicon/Intel binary targeting macOS 14+. Runtime checks are on Apple silicon
with macOS 27.2. **Locally ad-hoc signed; not notarized.**

## Changes since the first dated beta

- A missing USB original no longer stops unrelated originals or surviving Live Photo companions.
  The backup stays incomplete and missing files are never counted as verified. Other failures
  still stop the run; saved originals keep their incremental evidence.
- Backup History now retains the terminal failure explanation and unavailable-original count
  across dismissal and relaunch. Existing history is migrated without inventing old explanations.
- One Folder settings clearly explain that photos and videos are saved together per iPhone.
- The Air landing page is ready in the repository, visually compared across the family at
  desktop, tablet and phone sizes. Deployment is deferred.

The [initial beta notes](v0.1.0-beta.20261028.md) describe the wider USB backup, browsing,
recovery, per-iPhone destination and native UI feature set.

## Install

Open `CloakRoll-v0.1.0-beta.20261028.2.dmg`, drag CloakRoll to Applications, launch it and eject
the installer. For a trusted unnotarized copy blocked by macOS, follow
[Apple’s opening guidance](https://support.apple.com/en-us/102445).

Connect and unlock your iPhone, accept Trust if prompted and choose a backup folder. Keep another
independent copy of irreplaceable originals while evaluating the beta. Only media exposed over
USB is available; iCloud-only originals may be absent. No iPhone app is needed for backup.

## Remaining acceptance

Hardware is last: repeat the reported large backup on the affected Mac, incremental/new-capture
reconnect, cable/removable-volume interruption, full destination, sleep/wake and separate physical
iPhones. Full VoiceOver, sustained performance, older macOS/Intel runtime and clean-Mac distribution
checks remain open. Restore to a new iPhone stays in the conditional backlog. A successful local
launch does not establish notarization or Gatekeeper acceptance.

Use **Settings → About → Report a Bug** for feedback, including versions, destination type and
reproduction steps. Exclude personal photos, device identifiers, private paths and backup databases.
