## Failures found and corrected during packaging

The first image was withheld because hiding the signed `.app` extension added FinderInfo and failed
strict code-signature validation. The packager now leaves app extensions to Finder's preference and
only customizes the unsigned guide. The first native layout inspection then found that the title bar
clipped the footer. A 760×602-point frame now preserves the full 760×570-point artwork; the validator
enforces that size. After both fixes, the entire clean-commit beta pipeline passed again.

## Remaining boundaries

No physical transfer was performed for beta preparation. Cable/removable-volume interruption,
full disk/remount, new-capture reconnect/preview reuse, two-phone destination switching, sustained
frame/RSS profiling, full VoiceOver and system accessibility variants, macOS 14 and Intel runtime
acceptance remain open.
No Developer ID signing identity is available. This candidate is ad-hoc signed and unnotarized;
clean-Mac/quarantined-download acceptance remains untested. These limits must accompany beta sharing.
