## Native keyboard checks

Used the normal Debug app on Apple silicon/macOS 27.2 with 20 illustrated sample items.

- Tab → Down → Space enters the grid, selects the first photo and opens Info without clicking
  a photo. Command-] advances Info; Escape dismisses it without changing backup selection.
- Right → Shift-Right after dismissing Info selects the second and third items, demonstrating
  that keyboard focus returns to the grid.
- Command-F focuses search. With `0005` entered, Command-A selects text rather than all photos.
  Escape → Tab → Down → Space returns to the matching media and opens Info.
- Shift-Command-A clears selection and restores the new-items action state.
- The capture-date popover exposes From/Through labels, Quick Dates, Cancel and Apply; Escape
  dismisses it. Media cells expose filename, media kind, backup/selection state and Info/Copy
  Filename actions; date headings expose group selection actions.

These are actual native keyboard/AX checks, not a full screen-reader pass.
